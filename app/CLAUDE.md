# app/ — @halqo/app (Expo, React Native, TypeScript)

- Expo dev builds (not Expo Go). `name: "Halqo"`, `slug: "halqo"`, `scheme: "halqo"`, bundle/package `com.halqo.app`.
- Navigation: `expo-router` (bottom tabs Home / Search / Notifications / Messages + side drawer + stacks).
  Lists: `@shopify/flash-list`. Media: `expo-image`, `expo-video`. Motion: `react-native-reanimated`, gestures:
  `react-native-gesture-handler`.
- Styling: NativeWind classes and the tokens in `tailwind.config.js` only (`primary`, `surface`, `muted`, `border`,
  `danger`), light + dark via `dark:`. No inline style objects except for animations.
- UI follows PLAN.md section 2A (Twitter/X interaction patterns, Halqo brand). No reposts. Circle labels/numbers are
  shown only to the post's author; readers never see them.
- No crypto in TypeScript. Call `@halqo/core` for every encrypt/decrypt/derive/sign. Keys live in Keychain/Keystore
  under service `com.halqo.app.keys`.
- Never send plaintext content, names, circle numbers or private keys to the server; never log decrypted data.
- API client is generated from `docs/api/openapi.yaml`. Base URL from `app/.env` (`EXPO_PUBLIC_API_URL`).
- `app/ios` and `app/android` are generated by prebuild and never committed. Signing and push credentials live in EAS.
- Checks: `npm run typecheck`, `npm run lint`, `npm test`.
