# app/ — @circlo/app (Expo SDK 58, React Native 0.88, TypeScript)

- Expo dev builds (not Expo Go). `name: "Circlo"`, `slug: "circlo"`, `scheme: "circlo"`, iOS bundle ID `com.hellocirclo.app` (`com.circlo.app` was taken at Apple), Android package `com.circlo.app`
  (see `app.config.ts`).
- One codebase, three targets: iOS, Android and the **web app** (app.hellocirclo.com, `npm run build:web`, static
  single-page export deployed with `vercel.json`). Native-only modules get a `.web.ts` sibling with the same exports
  (`lib/storage`, `lib/media`, `lib/safety`, `lib/background-check`); check the web build after adding a native module.
- **Expo changes every SDK: don't trust memory.** Check the versioned docs for SDK 58
  (https://docs.expo.dev/versions/v58.0.0/ and https://docs.expo.dev/llms.txt) before using an Expo/RN API.
  Add packages with `npx expo install <pkg>` so versions match the SDK.
- Routes live in `src/app/` (expo-router): signed-out `(auth)` (welcome, signup, verify-email, login, forgot-password),
  then the drawer + `(tabs)` with Home / Search / Notifications / Messages, plus stack screens. `i/[token]` receives
  invite links. Non-route code goes in `src/components`, `src/lib`, `src/theme`.
- expo-router 58 vendors React Navigation: import navigation types, themes, `useNavigation` from `expo-router` /
  `expo-router/drawer`, never from `@react-navigation/*`.
- Styling: NativeWind 4 classes only, tokens from `src/theme/tokens.js` (shared with `tailwind.config.js`), every
  colour as `x dark:x-dark`. No inline style objects except for animations. Third-party components need
  `cssInterop` registration in `src/lib/interop.ts` before they accept `className`. Raw colour values (navigation
  options, icons) come from `usePalette()`.
- UI follows PLAN.md 2A (Twitter/X patterns, Circlo brand). No reposts. Circle labels/numbers only ever shown to the
  post's author (the server only sends a post's audience to its author). Every icon-only button has an `accessibilityLabel`.
- Data comes from the server over HTTPS (`src/api/client.ts`, typed from `docs/api/openapi.yaml`; regenerate with
  `npm run api:generate`). Owner decision 2026-11-01: no encryption in the app. The session (refresh token) lives in
  device storage (`lib/storage`: Keychain/Keystore on phones, localStorage on web); access tokens in memory only.
- Photos are re-encoded and stripped of EXIF/GPS, and videos lose their metadata boxes, before upload (`lib/media`).
  Never upload a picked original. Never log what people type or post.
- `app/ios`, `app/android` are generated by prebuild and never committed. Signing credentials live in EAS.
- Tests: jest-expo + @testing-library/react-native 14 (`render`/`fireEvent` are async: `await` them). The full
  drawer navigator needs Reanimated's native runtime, which doesn't load under jest; test screens and config directly.
- Checks: `npm run typecheck`, `npm run lint`, `npm test`, and `npm run build:web` for the web app.
