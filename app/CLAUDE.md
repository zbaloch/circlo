# app/ — @halqo/app (Expo SDK 58, React Native 0.88, TypeScript)

- Expo dev builds (not Expo Go). `name: "Halqo"`, `slug: "halqo"`, `scheme: "halqo"`, bundle/package `com.halqo.app`
  (see `app.config.ts`).
- **Expo changes every SDK: don't trust memory.** Check the versioned docs for SDK 58
  (https://docs.expo.dev/versions/v58.0.0/ and https://docs.expo.dev/llms.txt) before using an Expo/RN API.
  Add packages with `npx expo install <pkg>` so versions match the SDK.
- Routes live in `src/app/` (expo-router): root `Drawer` → `(tabs)` with Home / Search / Notifications / Messages,
  plus drawer screens (profile, circles, devices, settings, recovery, dev). Non-route code goes in `src/components`,
  `src/lib`, `src/theme`.
- expo-router 58 vendors React Navigation: import navigation types, themes, `useNavigation` from `expo-router` /
  `expo-router/drawer`, never from `@react-navigation/*`.
- Styling: NativeWind 4 classes only, tokens from `src/theme/tokens.js` (shared with `tailwind.config.js`), every
  colour as `x dark:x-dark`. No inline style objects except for animations. Third-party components need
  `cssInterop` registration in `src/lib/interop.ts` before they accept `className`. Raw colour values (navigation
  options, icons) come from `usePalette()`.
- UI follows PLAN.md 2A (Twitter/X patterns, Halqo brand). No reposts. Circle labels/numbers only ever shown to the
  post's author. Every icon-only button has an `accessibilityLabel`.
- No crypto in TypeScript. All encrypt/decrypt/derive/sign calls go to `@halqo/core` (`modules/halqo-core`, generated
  from `core/` by ubrn's `jsi2` flavour; the app must depend directly on `@ubjs/react-native`). Byte arrays cross as
  `ArrayBuffer`, u64 as `bigint`. Keys live in Keychain/Keystore under service `com.halqo.app.keys`.
- Never send plaintext content, names, circle numbers or private keys to the server; never log decrypted data.
- `app/ios`, `app/android` are generated by prebuild and never committed. Signing/push credentials live in EAS.
- Tests: jest-expo + @testing-library/react-native 14 (`render`/`fireEvent` are async: `await` them). The full
  drawer navigator needs Reanimated's native runtime, which doesn't load under jest; test screens and config directly.
- Checks: `npm run typecheck`, `npm run lint`, `npm test`.
